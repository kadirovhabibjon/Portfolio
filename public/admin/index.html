Token qanday olinadi?
  1. github.com/settings/personal-access-tokens/new ni oching
  2. Expiration — xohlagan muddat (masalan 1 yil)
  3. Repository access → Only select repositories →
  4. Permissions → Contents → Read and write
  5. Generate token → tokenni nusxalab shu yerga qo'ying

Token faqat shu brauzerda saqlanadi. Uni hech kimga bermang.
